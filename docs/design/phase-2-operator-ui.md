# Phase 2 operator UI direction

**Visual thesis:** LeadFlow AI is a calm, data-dense local operations ledger: paper-like surfaces,
dark ink, one teal action accent, thin rules, and evidence placed beside every operational claim.

**Evidence:** The operator must scan stored runs, resolve a consent-gated approval queue, inspect
source evidence, and understand metric denominators without mistaking synthetic fixtures for live
insurance outcomes. Phase 1 already established this restrained visual language and the owner chose
to extend it for Phase 2.

**Principles:**

1. Use one continuous workspace and strong reading order instead of a wall of interchangeable cards.
2. Keep status, provenance, denominator, failure, and synthetic labels next to the value they qualify.
3. Reserve teal for navigation, selection, progress, and safe operator actions; use text and shape as
   well as colour for state.
4. Prefer thin borders, compact type roles, tabular figures, and progressive disclosure over shadows
   or decoration.
5. Preserve readable wrapping, 24 px targets, visible focus, reduced motion, and evidence tables at
   desktop and 390 px.

**Tokens:** Inter/system UI type; system monospace for IDs and figures; warm paper surfaces; dark
green-black ink; restrained teal accent; semantic amber/red states; 8 px radius; 1 px rules; quiet
120 ms transitions disabled under reduced motion.

**Rejected direction:** A conventional rounded-card SaaS dashboard would make metrics look detached
from their definitions and weaken the evidence-first character of the dossier.
